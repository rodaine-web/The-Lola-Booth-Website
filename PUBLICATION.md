# Website publication state

Events and Gallery are unpublished at the owner’s request. Their source files are retained in `_unpublished/`, which `.vercelignore` excludes from deployments. Navigation, footer, Connect links, and sitemap entries have been removed. Direct URLs should return 404. The homepage event-type overview remains published; the request applies to the standalone pages.

Republishing requires explicit production approval, restoring the source files and intended links, verifying actual content, and deploying. Future CMS migration must preserve this unpublished state.
